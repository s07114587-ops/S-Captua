# 🛡️ Project S-Captcha (Shubhomoy Captcha)

> **The Free, Open-Source & Lightweight Security Captcha Solution.**  
> Built for maximum security with zero database costs and dynamic UI customization.

---

## 🌟 Why S-Captcha? (Importance for Web Developers)

In today's web, protecting your forms from bots, brute-force attacks, and spam is essential. However, traditional captchas often require heavy database setups, track user data aggressively, or ruin the UI/UX of modern websites.

**S-Captcha solves this with a developer-first approach:**

* ⚡ **Ultra-Fast & Lightweight:** Built with pure Vanilla HTML, CSS, and JS to ensure **zero load-time impact** on your main website.
* 🛡️ **Zero-Database Overhead:** Uses encrypted stateless verification methods, eliminating the need for expensive database infrastructure.
* 🔒 **Privacy-Focused:** Protects your users without selling or tracking their personal data.
* 🎨 **Fully Customizable:** Easily match the captcha design with your site's branding using built-in widget styles.

---

## 🔥 Key Features

* **3-Layer Security Shield:** 
  * Invisible Smart Captcha
  * Text & Interactive Challenge Captcha
  * Image Captcha with Invisible Honeypot
* **Multi-Color Widget Styles:** Choose between `Default`, `White`, `Black`, and `RGB (Glowing/Cyber)` themes to perfectly fit your web design.
* **Smart Rate Limiting:** Automatic temporary IP restriction to prevent brute-force and automated bot attacks.
* **OAuth Integration:** Secure authentication via Google, GitHub, and Facebook OAuth.
* **AGPLv3 Licensed:** Open-source, transparent, and copyleft-protected.

---

## 🎨 Widget Style Customization

S-Captcha provides direct snippet configuration for different color themes:

| Theme Option | Ideal For |
