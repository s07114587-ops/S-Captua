# 🛡️ S-Captcha (Shubhomoy Captcha)

> **The Free, Open-Source & Lightweight Security Captcha Solution.**
> Built for maximum security with zero database costs and dynamic UI customization.

---

## 🌟 Why S-Captcha?

In today's web, protecting your forms from bots, brute-force attacks, and spam is essential. Traditional captchas often require heavy database setups, track user data aggressively, or ruin the UI/UX of modern websites.

**S-Captcha solves this with a developer-first approach:**

* ⚡ **Ultra-Fast & Lightweight** — Built with pure vanilla HTML, CSS, and JS for zero load-time impact on your main site.
* 🛡️ **Zero-Database Overhead** — Uses encrypted, stateless verification, eliminating the need for expensive database infrastructure.
* 🔒 **Privacy-Focused** — Protects your users without selling or tracking their personal data.
* 🎨 **Fully Customizable** — Easily match the captcha design to your site's branding with built-in widget styles.

---

## 🔥 Key Features

* **3-Layer Security Shield**
  * Invisible Smart Captcha
  * Text & Interactive Challenge Captcha
  * Image Captcha with Invisible Honeypot
* **Multi-Color Widget Styles** — Choose between `Default`, `White`, `Black`, and `RGB` (glowing/cyber) themes to match your design.
* **Smart Rate Limiting** — Automatic temporary IP restriction to prevent brute-force and automated bot attacks.
* **OAuth Integration** — Secure authentication via Google, GitHub, and Facebook.
* **AGPLv3 Licensed** — Open-source, transparent, and copyleft-protected.

## 🎨 Widget Style Customization

S-Captcha ships with direct snippet configuration for different color themes:

| Theme Option | Ideal For |

| **Default** | Classic dark/light dynamic interfaces |
| **White** | Clean, minimalist, light-themed websites |
| **Black** | Stealth, dark-mode, minimalist aesthetics |

---

## 🚀 Quick Setup

Drop this single line into your site's `<head>` tag to activate S-Captcha instantly:

```html
<script src="https://www.scaptua.duckdns.org/widget.js" async defer></script>
```

> 📌 **Note:** For the full feature set, configuration options, and documentation, visit **[scaptua.duckdns.org](https://www.scaptua.duckdns.org/)**.
